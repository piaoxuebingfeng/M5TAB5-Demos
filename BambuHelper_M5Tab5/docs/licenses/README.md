# Bundled font licences

## Noto Sans SC (src/p4_sans_fonts.cpp)

- Family / weight: Noto Sans SC Regular, weight 400, 24 px
- Source: Google Fonts CSS API, `family=Noto+Sans+SC:wght@400`
  (`fonts.gstatic.com/s/notosanssc/v41/...ttf`, downloaded 2026-11-14, 10.5 MB TTF)
- Upstream: https://github.com/notofonts/noto-cjk (SIL Open Font License 1.1)
- Licence text: `NotoSansSC-OFL.txt` in this directory
- Generated by: `tools/build_cjk_font.py` - the sketch links a VLW (8-bit alpha
  bitmaps, TFT_eSPI/Bodmer format) built from the complete GB2312 repertoire,
  not the TTF itself.

Regenerate with:

```
python3 tools/build_cjk_font.py path/to/NotoSansSC-Regular.ttf --size 24
```

The 4 MB result is why `partitions.csv` in the sketch root declares a 15 MB
app slot instead of the board package's 6.5 MB default.
